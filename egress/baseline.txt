# egress/baseline.txt
# The hosts every allowlisted container may reach, on ports 80 and 443.
# Drafted from Docker sbx's "balanced" local policy (2026-10-27), with:
#   - sbx's "**." written as smokescreen's "*.", which matches any subdomain
#     but not the name itself; the name is listed on its own where it's needed;
#   - wildcards over storage anyone can create a bucket in left out
#     (*.amazonaws.com, *.blob.core.windows.net, *.googleapis.com,
#     *.googleusercontent.com, *.public.blob.vercel-storage.com): any agent
#     could write to an attacker's bucket through them. Allow the exact
#     bucket a project needs with `incs egress allow`;
#   - "crl*.digicert.com", which smokescreen can't match, written out.
#
# Every wildcard says why it's needed. Hosts marked "upload:" accept data from
# anyone with an account there; that's the accepted limit of an allowlist
# that names hosts, not accounts.
#
# incs never reads this file to build a policy. `incs egress refresh` shows
# how it differs from your approved copy
# (~/.config/incs/egress-approved-baseline.txt) and copies it only when you
# confirm. One host per line; "#" starts a comment.
